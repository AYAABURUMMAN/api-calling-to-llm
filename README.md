Week 2: Python, APIs and Pandas

This project includes two tasks:
1. task_llm_to_csv.py: Uses requests to call an LLM API and saves results to results.csv.
2. task_clean_json.py: Downloads JSON data, cleans it using Pandas, and saves the results to clean.csv and clean.json.
Setup:
- Install dependencies using pip install -r requirements.txt.
- Add your API key to a .env file.
Run:
- python task_llm_to_csv.py
- python tasj_clean_json.py
Note: The .env file is not uploaded to GitHub.
